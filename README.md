## 📝 함께 배우기

- 물건이 **여러 개(복수)** 라서 **is** 대신 **are**, **It's** 대신 **They're** 를 써요.
  - ❌ How much **is** the stickers? ✅ How much **are** the stickers?
  - ❌ **It's** 12,000 won. ✅ **They're** 12,000 won.
- 원래 둘이 한 쌍인 물건(*earmuffs, rain boots, pajamas*)도 늘 복수형으로 써요.
